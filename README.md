# tc1005s-snake

Juego Snake de freegames, modificado para la evidencia de TC1005S (Actividad 4).

Owner del repositorio: Angel Barush (thenewbaru). Fork: Jaime Samuel García Manzano (krannyy).

## Contenido
- `snake.py`: el juego.
- `README.md`: este archivo.

## Cómo correrlo
```
pip install freegames
python3 snake.py
```
Se mueve con las flechas del teclado.
